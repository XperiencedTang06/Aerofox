# Aerofox (Experimental)

Aerofox is a WIP experimentation for Firefox 153 ESR, based off of RinFox, an Internet Explorer 7/8 theme for Firefox 115 ESR, which i plan to migrate from, and Geckium, which has a modern foundation and JS.

## NOTICE:

This theme is currently in it's experimental phase, and i'm still developing the theme. Expect lots of bugs in this phase.

## GOALS:
1. Figure out how Geckium uses JS as an equivalent to "@supports moz-bool-pref("uservalue")", as that's required for the IE8 theme, theme options, and more.
2. Make everything look more like Internet Explorer 7, and soon, Internet Explorer 8.
